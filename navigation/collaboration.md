## Function and Purpose

**Confirmed organization:** SFI Foundation.

**Current ideation purpose:** Racers, crew members, inspectors, participating
manufacturers, and motorsports learners need clearer, mobile-friendly paths to
trustworthy specification and manufacturer information because safety information
can be difficult to locate, understand, and verify quickly.

The final user group, selected function, and product purpose remain undecided.
They will be narrowed only after the six storyboards and previous-team discussion.

### Candidate user actions

| Candidate action | Possible output | Status |
|---|---|---|
| Search using plain language | Relevant specification results with traceable sources | Idea only |
| Scan or enter a product/manufacturer identifier | Participation and reference information with clear limitations | Idea only |
| Review a mobile inspection or learning flow | Checklist, timeline, scenario, or next-step guidance | Idea only |
